ℹ️ Préparer votre campagne

Avant de lancer la campagne, votre fichier CSV doit contenir certaines colonnes selon ce que vous souhaitez faire.

📧 Envoi des e-mails

Colonne Obligatoire Description Exemples acceptés
Email ✅ Oui Adresse e-mail du destinataire Email, Mail, e-mail, courriel
Sujet ⚪ Non Objet du mail (sinon valeur par défaut config) Sujet, Objet, Subject
Client ⚪ Non Nom affiché dans les logs d'envoi Client, Nom, Prénom, Bénéficiaire

📄 Génération des documents (DOCX / PDF)

Colonne Obligatoire Description Exemples acceptés
Nom_fichier ✅ Oui Nom du fichier généré (sans extension) Nom_fichier, Fichier, filename
💡 Les noms de colonnes ne sont pas sensibles à la casse et les variantes courantes sont détectées automatiquement. En cas de doute, l'étape suivante vous permettra de faire le lien manuellement.

✏️ Personnalisation des modèles (placeholders)

Dans vos modèles DOCX et HTML, vous pouvez insérer des variables qui seront remplacées automatiquement par les valeurs du CSV.

La syntaxe est {{ '{{Nom_de_la_colonne}}' }} — le nom doit correspondre exactement à l'en-tête de la colonne dans le CSV.

Dans le CSV Placeholder dans le modèle Exemple de résultat
Client {{ '{{Client}}' }} Dupont Marie
Montant {{ '{{Montant}}' }} 45.00
Ville {{ '{{Ville}}' }} Saint-Brieuc
💡 Exemple : Bonjour {{ '{{Client}}' }}, veuillez trouver ci-joint votre document pour un montant de {{ '{{Montant}}' }} €.

🚀 Lancer une campagne

1. Préparer vos fichiers

Vous aurez besoin de trois fichiers (deux si vous souhaitez n'envoyer qu'un mail personnalisé) :

  • La liste des destinataires et des infos associées : fichier .xlsx, .xls ou .csv contenant une ligne par client. Privilégier l'extension .xslx pour ce fichier
  • Le modèle de courrier (qui sera joint au format pdf) : fichier .docx (Word) avec vos placeholders : exemple => {{ '{{Nom_colonne}}' }}.
  • Le modèle d'email : fichier .docx ou .html avec le corps du message, également personnalisable avec des placeholders.

2. Sélectionner et importer les fichiers

Sur la page principale, déposez chaque fichier dans la zone correspondante (glisser-déposer ou clic pour parcourir) et cliquer sur "Importer".

3. Vérifier la correspondance des colonnes

L'application détecte automatiquement les colonnes de votre fichier. Vérifiez que chaque champ est bien associé à la bonne colonne et corrigez si nécessaire.

4. Choisir le mode d'envoi

  • Mode test : génère les PDF et les mails (si option cochée) sans les envoyer => juste une visualisation à l'écran — idéal pour vérifier le résultat avant l'envoi réel.
  • Mode envoi : génère les PDF et envoie les emails à chaque destinataire.

5. Prévisualiser avant de lancer

Cliquez sur 👁️ Prévisualiser pour vérifier la liste des destinataires et l'aperçu d'une fiche PDF avant tout envoi. Aucun document n'est généré à cette étape.

Si tout est correct, cliquez sur ✉️ Confirmer et lancer pour démarrer le traitement réel. Vous pouvez aussi cliquer directement sur 🚀 Lancer directement si vous êtes sûr de vos fichiers.

Une fois le traitement lancé, vous êtes redirigé vers une page de suivi qui affiche le journal d'exécution en temps réel : génération des PDF, envois d'emails, éventuelles erreurs. Le badge de statut passe de En cours… à ✅ Terminé ou ❌ Erreur à la fin du traitement.

En fin de campagne, deux boutons apparaissent : ← Retour à l'accueil et 💾 Télécharger le log pour conserver une trace complète du traitement.
